# Portofolio Muhammad Raditya Duta Pratama

Website portofolio pribadi saya sebagai siswa PPLG (Pengembangan Perangkat Lunak dan Gim) di SMK TI Dwi Guna. Dibuat dengan HTML, Tailwind CSS, dan JavaScript murni tanpa framework.

**Live demo:** https://mradityaad.github.io/Porto-radit/

## Tentang

Saya seorang web developer dan game developer pemula yang suka mengubah ide menjadi sesuatu yang bisa dipakai dan dimainkan. Portofolio ini berisi profil singkat, tech stack, project yang pernah saya buat, dan kontak.

## Fitur

- Desain hitam-putih yang bersih dan responsif (HP, tablet, desktop)
- Animasi muncul saat scroll (scroll reveal)
- Efek teks kode yang diketik otomatis di bagian About
- Transisi layar saat pindah section lewat navbar
- Navbar yang berubah tema mengikuti section dan menu burger untuk HP
- Cursor custom di desktop dan progress bar scroll
- Teks berjalan (marquee) untuk daftar tech stack
- Tombol kontak langsung ke WhatsApp, Gmail, dan GitHub
- Tombol download CV

## Tech Stack

| Kategori | Teknologi |
| --- | --- |
| Frontend | HTML5, CSS3, JavaScript |
| Styling | Tailwind CSS (CDN) |
| Font | DM Sans, Space Grotesk, JetBrains Mono (Google Fonts) |

## Project yang Ditampilkan

1. **Website Sederhana**: website statis dengan HTML5 dan CSS3, memakai Flexbox, Grid, dan desain responsif.
2. **Desain Antarmuka Aplikasi**: wireframe sampai prototype interaktif di Figma.
3. **Game Flappy Bird 2D**: game dibuat di Scratch dengan kontrol karakter, deteksi tabrakan, skor, dan Game Over.

## Menjalankan di Lokal

Tidak perlu install apa pun.

1. Clone repo ini:
   ```bash
   git clone https://github.com/MradityaaD/Porto-radit.git
   ```
2. Buka folder `Porto-radit`.
3. Buka `index.html` di browser, atau pakai ekstensi Live Server di VS Code.

> Tailwind CSS, font, dan ikon dimuat dari CDN, jadi butuh koneksi internet agar tampilannya lengkap.

## Deploy

Situs ini di-host dengan GitHub Pages. Aktifkan lewat **Settings → Pages**, pilih branch `main` dan folder `/ (root)`.
